# Predi-o-de-Evas-o-Estudantil-no-Ensino-Superior
Classificação preditiva para identificação precoce de evasão universitária. O projeto avalia a antecedência temporal da predição sem vazamento de dados, a relevância de atributos socioeconômicos/acadêmicos e o equilíbrio entre desempenho e interpretabilidade para suporte à tomada de decisão pedagógica.
